### 任务一：验证时效修复

- 问题：输入侧 7 天过滤已部署，但尚未经过下一次自然生成验证。
- 方案：读取 2026-07-29 缓存早报和同日原始快照，运行 8 项确定性检查。
- 结论：时效检查通过；结构、格式、数量、Top 5 和 GitHub 日榜继续通过。

### 任务二：修正来源误报

- 问题：早报中的 36氪 URL 与原始输入只差 `www` 和 `?f=rss`，被判为未知来源。
- 方案：来源、时效、重复和 GitHub 排序比较前统一 URL 主机、片段和已知跟踪参数。
- 结论：同源链接不再误报；不同路径和有意义的查询参数仍保留区分。
