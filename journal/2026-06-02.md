### 3 CI deploy 修复

**问题**：CI Deploy workflow 连续失败三次。

**排查**：
1. 第一次：服务器有未提交的本地改动（上次手动 `sed` 改的），`git pull` 冲突 → 加 `git checkout -- .`
2. 第二次：healthcheck 用 `curl http://127.0.0.1:9900/` 访问根路径返回 404 → 改为 `/mcp/scout`
3. 第三次：`/mcp/scout` 无 auth token 返回 401 → 改为 TCP socket 检查（`python3 -c "import socket; ..."`）
4. 第四次：成功 ✅

额外加 `--no-cache` 确保全量重建。

**Commit**: `cf32bf6`, `53fa0bd`, `56dea57`

### 4 服务器配置修复

**问题**：MCP 端点返回 `Unauthorized` + `Invalid Host header`。

**排查**：
- Redis URL 缺密码（`redis://localhost:6379/0` → `redis://:PASSWORD@localhost:6379/0`）
- `allowed_hosts` 未配置（Cloudflare Tunnel 转发时 Host 是 `open.linglong.wiki`）
- 两个问题均为上次部署时遗漏

**Commit**: 无（直接 `sed` 修改服务器 `.scout.yml`）
