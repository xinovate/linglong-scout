## 任务详情

### 任务 1：SearXNG 贡献度分析

**问题**：SearXNG 运维成本高（Docker 容器 + nginx 反代 + API Key），需评估其实际价值。

**分析**：6 月 5 日早报 48 条信息全部来自 RSS 和 GitHub，SearXNG 24 个精准查询零引用。RSS 18 源已全面覆盖人名/公司/产品/政策/学术。

**结论**：SearXNG 贡献为零，运维成本不值得。

### 任务 2：SearXNG 完全移除

**方案**：14 个源码文件改动，采集从三路（SearXNG + GitHub + RSS）改为两路（GitHub + RSS）。

**关键变更**：
- `collect.py`：删除 `_searxng_search`、`_search_all_keywords`、`_dedup_results`、`_is_noise_url`、`_NOISE_DOMAINS`；`collect()` 不再接受参数
- `agent.py`：删除 `_format_results`；prompt 移除 `{search_results}` 占位符
- `raw_store.py`：删除 `_normalize_searxng`；`_SOURCES` 改为 `("rss", "github")`
- `mcp/tools.py`：删除 `search_web` 工具（7→6 工具）；`execute_package` 移除 `keywords`/`max_results` 参数
- `config.py`：删除 `searxng_url`、`searxng_api_key`、`search_timeout`
- `package.py`：删除 `SearchQueryConfig` 类和 `search_queries` 字段
- Prompt 模板：删除 `{search_results}` 段和 SearXNG 引用规则
- 6 个测试文件重写，154 测试全通过
