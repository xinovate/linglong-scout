## 任务详情

### 任务 1：LLM 双协议兼容

**问题**：本地 `.env` 配置智谱 OpenAI 端点（`api/coding/paas/v4`），但 `agent.py` 硬编码 Anthropic 协议（`/v1/messages` + `x-api-key`），导致 404。服务器定时任务连续两天早报生成失败。

**方案**：`_call_llm` 根据 `base_url` 是否包含 `/anthropic` 自动选择协议。拆出 `_build_anthropic_request`、`_build_openai_request`、`_parse_llm_response` 三个函数。调用方和 retry 逻辑不变。

**关键差异**：
- Anthropic: `/v1/messages` + `x-api-key` + `system` 独立字段 → `content[0].text`
- OpenAI: `/chat/completions` + `Authorization: Bearer` + `system` 在 messages 内 → `choices[0].message.content`

### 任务 2：Hook matcher 修复

**问题**：`journal-check` hook 匹配 `Bash(git push*)`，但链式命令 `git add && git commit && git push` 以 `git add` 开头，不匹配 `git push*` 前缀模式。

**方案**：三个 hook 的 `if` 模式统一改为 `*git commit*` 和 `*git push*`（包含式匹配），覆盖链式命令场景。

**根因**：Claude Code hook matcher 对 Bash 工具的完整命令字符串做前缀匹配，`&&` 链式命令使 `git push` 不在开头。

### 任务 3：Claude Code 理解缺失项

**对比官方文档发现的盲区**：

1. **Hooks 8 个事件只用了 2 个** — PostToolUse（已加 ruff）、Stop、PreCompact、SessionEnd 等未用
2. **Hooks 支持 JSON 输出控制权限** — 可自动 allow/deny 工具调用，不仅依赖 exit code
3. **Hooks 可匹配 MCP 工具** — `mcp__linglong-scout__*` 格式
4. **Rules vs Hooks 本质区别** — Rules 是软约束（文本指令），Hooks 是硬约束（代码拦截）。关键规则必须 hook 化
5. **Skills 支持 `allowed-tools` 字段** — 可限制激活时的工具范围

### 任务 4：/health 端点 + HTTP 级 healthcheck

**问题**：OpenClaw cron 定时任务偶尔报"工具不可用"，根因是远程 MCP 连接不稳定。Docker healthcheck 只测 TCP 端口连通，不验证 HTTP 应用层是否就绪。

**方案**：
1. 添加 `HealthMiddleware`（中间件方式），`GET /health` 返回 `{"status": "ok"}`，免鉴权
2. 初始方案用 Starlette Mount 包装 MCP app，导致 MCP lifespan/task group 未初始化（500 错误），改为中间件方式解决
3. Dockerfile + docker-compose healthcheck 从 TCP socket 改为 `urlopen('http://localhost:9900/health')`

**改动**：`server.py`（HealthMiddleware）+ `Dockerfile`（healthcheck）+ `docker-compose.yml`（healthcheck）+ `tests/mcp/test_health.py`（2 个测试）+ `docs/design/06-mcp.md`（文档同步）

### 任务 6：Cloudflare Bot Check 放行

**问题**：Cloudflare Error 1010（浏览器签名检测）拦截 Python/Node HTTP 客户端的 UA，导致 OpenClaw 偶发连接失败。

**方案**：Cloudflare Dashboard 自定义规则，`http.request.uri.path wildcard "/mcp/*"` 跳过浏览器完整性检查。MCP 端点已有 Token 认证保护，安全性不受影响。

**验证**：`curl -H "User-Agent: python-httpx/0.28.1"` 返回 401（Token 认证拦截），不再返回 1010。

### 任务 7：LLM timeout 调优

**方案**：`llm_timeout` 从 120s 调至 300s。服务器 `.scout.yml` 和 `.scout.example.yml` 同步更新。

**验证**：手动触发 `generate_brief`，3 分 49 秒完成，输出 4065 字符，3 个表格 + 3 个列表，格式正确。
