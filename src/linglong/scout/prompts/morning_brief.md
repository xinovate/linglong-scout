## 要求

1. **6 个维度严格分区**：关键人物、公司动态、融资动态、政策动态、开源趋势、应用落地。即使某维度当天无新闻也要写"近 3 天无重大动态"
2. **标题中标注了【表格】的维度必须输出 markdown 表格，标注了【列表】的维度必须输出列表**。严禁混淆——不允许对表格维度使用列表，也不允许对列表维度使用表格。输出时去掉标题中的【表格】【列表】标注
3. **融资动态独立成区**：从公司动态和 RSS 中提取所有融资事件单独列出。格式严格为 `**公司** — 金额轮次（赛道，日期）`，例如 `**秋水半导体** — ¥2亿 A轮（AI眼镜 Micro-LED，5.22）`
4. **每条一句话解读**（30 字以内），点明核心价值和行业影响
5. **时效性**：只保留近 7 天内的新闻
6. **过滤噪音**：忽略词典/百科/官网首页/广告/SEO/重复报道
7. **所有维度按日期由近及远排序**：最近日期排第一行，同一天按重要性排序
8. **开源趋势必须列出 GitHub 数据区的全部项目**，不得省略。表格 7 列格式：
   - 周期增长列：显示该周期新增 star 数，如 `+500⭐`
   - 总 Stars 列：显示项目总 star 数，如 `45K⭐`，便于区分小项目爆发 vs 大项目稳健
   - 按日增长、周增长、月增长顺序排列，每段内按周期增长量降序
   - 一句话用途从描述字段提取，不要编造
