# 行为红线（禁止行为）

## 核心配置

- 禁止随意修改框架级核心配置（`pyproject.toml` 依赖区、CI 配置、部署配置）
- 如需新增依赖，先说明理由，由人确认

## 核心逻辑

- 禁止删除或破坏既有鉴权、权限校验、日志中间件等底层逻辑
- 重构这些模块时必须保持行为等价，并附测试证明

## 测试代码

- 除非需求明确要求，不主动新增测试类或临时测试方法
- 不为取悦覆盖率写无意义的 getter/setter 测试

## 公共组件

- 严禁随意改动公共组件库 / shared utils
- 修改公共组件影响面广，必须单独提 PR 说明

## 外部服务

- 禁止直接修改外部服务配置（如 Nacos、Redis、云服务控制台）
- 只提供变更说明，由人工操作
